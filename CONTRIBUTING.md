# Contributing

Thanks for helping improve AI Marketplace.

1. Open an issue before starting a large or behavior-changing contribution.
2. Create a focused branch and keep generated bundles in sync with their sources.
3. Run `npm.cmd test`, `npm.cmd run lint`, and `npm.cmd run compile`.
4. Open a pull request describing the behavior change, tests, and security implications.

Never commit credentials or private repository content. Follow [SECURITY.md](SECURITY.md) for vulnerability reports.
