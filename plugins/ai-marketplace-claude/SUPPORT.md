# AI Marketplace Support

Use GitHub Issues: https://github.com/Idov31/ai-marketplace/issues

Include Claude Code and plugin versions, operating system, package source id,
package type, target scope, and a redacted error. Never include tokens,
authorization headers, private repository contents, or other credentials.
Report security-sensitive issues through GitHub private vulnerability reporting:
https://github.com/Idov31/ai-marketplace/security/advisories/new
