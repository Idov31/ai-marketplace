# AI Marketplace Support

Use GitHub Issues for bug reports and support requests:
https://github.com/Idov31/ai-marketplace/issues

Include the interface used (VS Code or Codex), operating system, extension or
plugin version, package source id, package type, target scope, and a redacted
error message. Never include GitHub tokens, authorization headers, private
repository contents, or other credentials.

Report security-sensitive issues through the private process in
[SECURITY.md](SECURITY.md). Do not open a public issue containing credential or
exploit details.
